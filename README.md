# Threads Auto (US) — Releases

This repository is used **only for installer downloads and automatic updates**. It contains no source code.

- Latest installer: download `*-Setup-*.exe` from **Releases** on the right.
- Keep the app open and new versions download automatically; restart the app to apply them.

## Before you install
1. **Node.js** — https://nodejs.org (LTS button)
2. **Claude Code** — in a terminal (cmd) run `npm i -g @anthropic-ai/claude-code`, then sign in with `claude` (a paid Claude plan is required)
3. On first launch, follow the on-screen guide and press **Install browser (once)**
